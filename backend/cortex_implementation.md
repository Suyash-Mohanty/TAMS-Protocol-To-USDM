# Cortex LLM Implementation Guide

## Purpose

This document provides generalized, step-by-step instructions for integrating Cortex LLM into a backend project generated by this AI-First Backend Workflow. It is a **conditional implementation guide** — Cortex integration is applied **only when the user specifies it** in `PROJECT_OVERVIEW.md` (see trigger condition below).

When Cortex integration is not specified, the standard LLM integration as described in `FEATURE_IMPLEMENTATION.md` takes effect.

---

## Trigger Condition

Cortex integration is activated **only when** the `PROJECT_OVERVIEW.md` contains the following field (analogous to how `Deployment Target` activates FastAPI vs AWS Lambda paths):

```
LLM Provider (MANDATORY): Cortex
```

If the field reads anything other than `Cortex` (e.g., `OpenAI`, `Bedrock`, `Azure OpenAI`, other), or is absent, skip this document entirely and follow the LLM integration specified in `FEATURE_IMPLEMENTATION.md`.

## Cortex-model-configuration-Step: Cortex Model Configuration Setup

**When to run:** Once per project, **before pre-step**, only when `LLM Provider: Cortex` AND `Cortex Model Name` in `PROJECT_OVERVIEW.md` is set to `NEW`, blank, or missing.

**When to skip:** `Cortex Model Name` already contains a valid registered model name (e.g., `agentic-test112114`).

### Decision

| `Cortex Model Name` value | Action |
|---------------------------|--------|
| Valid existing name (e.g., `agentic-test112114`) | Skip Cortex-model-configuration-Step; use that name in `src/core/config.py` |
| `NEW` / blank / missing | Run Cortex-model-configuration-Step to create a new model config |

### Steps

1. **Gather minimum required inputs from the developer** (do not invent values):
   - `name` — unique model identifier (lowercase alphanumeric + dashes), e.g., `myproject-rag-v1`
   - `displayName` — human-readable name
   - `model_description` — short purpose statement
   - `auth.owners` — at least one owner (user ID / email)
   - `chain[0].chain_class` — pick one based on use case: `doc-chain` (RAG), `model-only-chain` (no RAG), `agent-chain` (tools)
   - `model_versions[0].model_class` + `model_iteration` — underlying LLM

   If any of the above is missing, **STOP and ask the developer**. Everything else uses defaults.

   **When recommending or validating `model_class` + `model_iteration`, use ONLY the combinations in the table below. Never suggest a model_class or iteration that is not listed here — those are either deprecated or do not exist.**

   | chatbot-models | 1, 2 |

   | cohere | 1, 2, 3, 4 |

   > **Note:** This table is sourced from `GET /models` as of 2026-05-15. If the developer requests a combination not in this table, inform them it is either deprecated or unrecognised, and ask them to confirm before proceeding.

2. **Build the minimal request body** (all other fields use Cortex defaults):

   ```json
   {
     "name": "<from-developer>",
     "displayName": "<from-developer>",
     "model_description": "<from-developer>",
     "auth": {
       "owners": ["<owner-id>"],
       "private": true
     },
     "chain": [
       { "chain_class": "doc-chain", "model_iteration": 1, "order": 1, "chain_params": {} }
     ],

   ```

   For the **full ModelConfig schema** (prompts, realtime_config, hybrid_search, rerank, session_config, all 14 prompt types, all 10 chain types), see the appendix **"Full ModelConfig Schema Reference"** at the bottom of this file or request from the developer if advanced configuration is required.

3. **Create the model config** by running the following Python script manually.

   > **Do not execute this as a post-generation command.** Generate the script below as `scripts/create_cortex_model.py`, fill in the values gathered in Step 1, and instruct the developer to run it once from the project root:
   >
   > ```
   > python scripts/create_cortex_model.py
   > ```

   **Generated file: `scripts/create_cortex_model.py`**

   ```python
   """
   One-time script to register a new Cortex model configuration.
   Run manually from the project root: python scripts/create_cortex_model.py
   Do NOT import or call this from application code.
   """

   import json
   import sys
   import os

   # Ensure project root is on the path so light_client can be imported
   sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))

   from light_client import LIGHTClient, AUTH_METHOD_AZURE_AD

   # ── Fill in values gathered from the developer (Step 1) ──────────────────
   CORTEX_BASE = os.environ.get("CORTEX_BASE", "https://api.cortex.lilly.com")

   MODEL_PAYLOAD = {
       "name": "<from-developer>",            # unique model identifier
       "displayName": "<from-developer>",     # human-readable name
       "model_description": "<from-developer>",
       "auth": {
           "owners": ["<owner-id>"],          # at least one owner email/ID
           "private": True,
       },
       "chain": [
           {
               "chain_class": "doc-chain",    # doc-chain | model-only-chain | agent-chain
               "model_iteration": 1,
               "order": 1,
               "chain_params": {},
           }
       ],
       "model_versions": [
           {
               "model_class": "lilly-openai", # underlying LLM class
               "model_iteration": 6,
               "priority": 1,
           }
       ],
       "labels": {},
   }
   # ─────────────────────────────────────────────────────────────────────────


   def main() -> None:
       print("Authenticating with Cortex (Azure AD device code flow)...")
       client = LIGHTClient(auth_method=AUTH_METHOD_AZURE_AD, env="PRD")

       print(f"Creating Cortex model: {MODEL_PAYLOAD['name']}")
       response = client.post(
           f"{CORTEX_BASE}/model",
           json=MODEL_PAYLOAD,
       )

       if response.status_code == 200:
           data = response.json()
           registered_name = data.get("name", MODEL_PAYLOAD["name"])
           print(f"\nSuccess! Model registered as: {registered_name}")
           print(
               f"\nNext step: update PROJECT_OVERVIEW.md:\n"
               f"  Cortex Model Name (MANDATORY if LLM Provider = Cortex): {registered_name}"
           )
       elif response.status_code == 400:
           print(f"\nValidation error (400): {response.text}")
           print("Fix the MODEL_PAYLOAD values above and re-run.")
           sys.exit(1)
       elif response.status_code == 403:
           print("\nPermission denied (403). Ensure the owner ID in MODEL_PAYLOAD has Cortex access.")
           sys.exit(1)
       else:
           print(f"\nUnexpected response ({response.status_code}): {response.text}")
           sys.exit(1)


   if __name__ == "__main__":
       main()
   ```

   **Error handling:**
   - `400` — fix validation errors printed to the console, update `MODEL_PAYLOAD`, re-run.
   - `403` — ensure the owner ID in `MODEL_PAYLOAD["auth"]["owners"]` has Cortex access.

4. **Record the returned `name`** back into `PROJECT_OVERVIEW.md`:

   ```
   Cortex Model Name (MANDATORY if LLM Provider = Cortex): <returned-name>
   ```

5. **Handle errors**: See error handling notes in the generated script above.

**Result:** A registered Cortex model name is recorded in `PROJECT_OVERVIEW.md`. All subsequent steps (Level 1, Level 2) read this name from config and never re-create it.

> **Note for Copilot:** Generate `scripts/create_cortex_model.py` with the values from Step 1 filled in, then **stop**. Do not execute it. Instruct the developer to run it manually and paste the returned model name into `PROJECT_OVERVIEW.md` before proceeding.

## What is Cortex?

Cortex is an internal, organization-managed LLM API gateway that proxies access to multiple underlying models (OpenAI GPT-4/o-series, Claude, Amazon Nova, LLaMA, etc.) through a single, authenticated endpoint. It requires authentication via the **LIGHT Client**, an internal Python library that supports:

- **Azure AD (device code flow)** — default for interactive environments (local dev, Streamlit apps)
- **AWS IAM (SigV4)** — for serverless / Lambda environments

The Cortex API base URL is `https://api.cortex.lilly.com` (configurable via env var `CORTEX_BASE`).

## Pre-Conditions Before Starting

Before implementing Cortex integration, confirm the following are available:

1. **`light_client/` folder** — must be present in the project root. This folder contains the `LIGHTClient` class and authentication helpers. It is **never modified** by codegen — treat it as a read-only dependency.
2. **Cortex model name(s)** — the Cortex-registered model name(s) to use (e.g., `"agentic-test112114"`, `"configmodelonly4047296"`). These are **different** from underlying LLM names (e.g., `gpt-4`). Populate from `PROJECT_OVERVIEW.md`.
3. **Auth method** — Azure AD (default) for interactive/FastAPI; AWS for Lambda. Read from `PROJECT_OVERVIEW.md`.
4. **Cortex base URL** — defaults to `https://api.cortex.lilly.com`. Override via env var if project uses a different environment (dev: `stable.dev.cortex.lilly.com`, qa, prd).

### Step 3 — Create `src/integrations/cortex_client.py`

This is the **single integration point** for all Cortex API calls. It wraps `LIGHTClient` with:
- Session caching (reuse authenticated client for 30 minutes)
- Retry logic for transient authentication failures
- Standardized response parsing
- Structured error handling

Generate this file using the template below. Substitute auth method based on deployment target.

#### Template — `src/integrations/cortex_client.py`

```python
"""
Cortex LLM API client for <PROJECT_NAME>.

Wraps LIGHTClient with session caching, retry logic, and standardized
response handling for Cortex model API calls.
"""

import logging
import time
from typing import Any, Dict, List, Optional

import requests as _requests
from light_client import LIGHTClient, AUTH_METHOD_AZURE_AD, AUTH_METHOD_AWS

from src.core.config import (
    CORTEX_BASE,
    CORTEX_PRIMARY_MODEL,
    CORTEX_AUTH_ENV,
    CORTEX_TOKEN_REFRESH_SECONDS,
    CORTEX_MAX_RETRIES,
    CORTEX_REQUEST_TIMEOUT,
)

logger = logging.getLogger(__name__)

# Module-level client cache — shared across requests within the same process
_client_instance: Optional[LIGHTClient] = None
_last_auth_time: Optional[float] = None

# Auth method selection: set based on deployment target
# FastAPI → AUTH_METHOD_AZURE_AD (interactive device code flow)
# AWS Lambda → AUTH_METHOD_AWS (SigV4 using Lambda execution role)
_AUTH_METHOD = AUTH_METHOD_AZURE_AD  # REPLACE with AUTH_METHOD_AWS for Lambda target


def get_authenticated_client(force_refresh: bool = False) -> LIGHTClient:
    """
    Return a cached and authenticated LIGHTClient, refreshing when expired.

    Args:
        force_refresh: Force re-authentication even if the cached client is valid.

    Returns:
        An authenticated LIGHTClient instance.
    """
    global _client_instance, _last_auth_time

    current_time = time.time()
    token_stale = (
        _last_auth_time is None
        or (current_time - _last_auth_time) > CORTEX_TOKEN_REFRESH_SECONDS
    )

    if force_refresh or _client_instance is None or token_stale:
        logger.info("Initializing authenticated Cortex client (env=%s)", CORTEX_AUTH_ENV)
        _client_instance = LIGHTClient(auth_method=_AUTH_METHOD, env=CORTEX_AUTH_ENV)
        _last_auth_time = current_time

    return _client_instance


def call_model(
    prompt: str,
    model_name: Optional[str] = None,
    timeout: int = CORTEX_REQUEST_TIMEOUT,
) -> Dict[str, Any]:
    """
    Send a prompt to a Cortex model and return the parsed response.

    Args:
        prompt: The prompt text to send to the model.
        model_name: Cortex model name to use. Defaults to CORTEX_PRIMARY_MODEL.
        timeout: HTTP request timeout in seconds. Defaults to CORTEX_REQUEST_TIMEOUT (30s).

    Returns:
        Dict with keys:
            - status (str): "success" or "error"
            - response (str): Model response text (on success)
            - error_message (str): Error description (on failure)
            - error_code (int): HTTP status code (on failure)
            - timed_out (bool): True when the request timed out (on failure)
    """
    target_model = model_name or CORTEX_PRIMARY_MODEL

    for attempt in range(CORTEX_MAX_RETRIES):
        try:
            client = get_authenticated_client(force_refresh=(attempt > 0))
            payload = {"prompt": prompt, "default_knowledge": True}
            result = client.get(
                f"{CORTEX_BASE}/model/ask-with-custom-prompt/{target_model}",
                params=payload,
                timeout=timeout,
            )

            if result.status_code == 200:
                data = result.json()
                response_text = data.get("message") or data.get("answer") or str(data)
                return {"status": "success", "response": response_text}

            if result.status_code == 403 and attempt < CORTEX_MAX_RETRIES - 1:
                logger.warning(
                    "Cortex auth error (attempt %d/%d), retrying...",
                    attempt + 1,
                    CORTEX_MAX_RETRIES,
                )
                time.sleep(2)
                continue

            return {
                "status": "error",
                "error_code": result.status_code,
                "error_message": result.text,
            }

        except (TimeoutError, _requests.exceptions.Timeout):
            logger.warning(
                "Cortex model call timed out (attempt %d, timeout=%ds)",
                attempt + 1,
                timeout,
            )
            return {
                "status": "error",
                "error_message": f"Request timed out after {timeout}s",
                "timed_out": True,
            }
        except Exception as exc:
            if attempt < CORTEX_MAX_RETRIES - 1:
                logger.warning("Cortex call error, retrying: %s", str(exc))
                time.sleep(2)
                continue
            logger.error("Cortex call failed after %d attempts: %s", CORTEX_MAX_RETRIES, str(exc))
            return {"status": "error", "error_message": str(exc)}

    return {"status": "error", "error_message": f"Failed after {CORTEX_MAX_RETRIES} attempts"}


def list_available_models(
    is_admin: Optional[bool] = None,
    is_private: Optional[bool] = None,
    app_binding: Optional[str] = None,
) -> List[Dict[str, Any]]:
    """
    Retrieve all Cortex models accessible to the authenticated user.

    Args:
        is_admin: Filter to models where the user is owner.
        is_private: Filter to private models only.
        app_binding: Filter by application binding value.

    Returns:
        List of model configuration dicts. Returns empty list on error.
    """
    client = get_authenticated_client()
    params: Dict[str, Any] = {}

    if is_admin is not None:
        params["is_admin"] = is_admin
    if is_private is not None:
        params["is_private"] = is_private
    if app_binding is not None:
        params["app_binding"] = app_binding

    try:
        result = client.get(
            f"{CORTEX_BASE}/model",
            params=params or None,
        )
        if result.status_code == 200:
            return result.json()
        logger.error("Failed to list models: %s - %s", result.status_code, result.text)
        return []
    except Exception as exc:
        logger.error("Error listing Cortex models: %s", str(exc))
        return []


def test_connection() -> Dict[str, Any]:
    """
    Verify Cortex connectivity and authentication by listing models.

    Returns:
        Dict with status ("success"/"error") and a descriptive message.
    """
    try:
        client = get_authenticated_client(force_refresh=True)
        result = client.get(f"{CORTEX_BASE}/model")

        if result.status_code == 200:
            models = result.json()
            return {
                "status": "success",
                "message": f"Connected to Cortex. {len(models)} models available.",
                "model_count": len(models),
            }
        if result.status_code == 403:
            return {
                "status": "error",
                "message": "Authentication failed (403). Re-authenticate.",
                "error_code": 403,
            }
        return {
            "status": "error",
            "message": f"Cortex returned status {result.status_code}",
            "error_code": result.status_code,
        }
    except Exception as exc:
        return {"status": "error", "message": f"Connection error: {str(exc)}"}
```

**Deployment target substitution rule:**
- `FastAPI` target → keep `_AUTH_METHOD = AUTH_METHOD_AZURE_AD`
- `AWS Lambda` target → replace with `_AUTH_METHOD = AUTH_METHOD_AWS`

### Step 4 — Update `src/services/<feature>_service.py`

In the service layer, replace any direct LLM SDK calls with calls to `cortex_client.call_model()`. The service layer remains **framework-agnostic** and is shared between FastAPI routes and Lambda handlers.

**Pattern — calling Cortex in a service:**

```python
from src.integrations.cortex_client import call_model
from src.core.exceptions import LLMServiceError, LLMTimeoutError

def generate_response(user_prompt: str) -> str:
    """
    Generate a response using the configured Cortex LLM model.

    Args:
        user_prompt: The user-provided prompt text.

    Returns:
        The model's response text.

    Raises:
        LLMTimeoutError: If the Cortex API call times out.
        LLMServiceError: If the Cortex API call fails or returns invalid JSON.
    """
    result = call_model(prompt=user_prompt)

    if result.get("timed_out"):
        raise LLMTimeoutError("AI request timed out. Please try again.")

    if result["status"] != "success":
        raise LLMServiceError(
            f"Cortex model call failed: {result.get('error_message', 'unknown error')}"
        )

    return result["response"]


def _parse_json_response(raw_response: str) -> dict:
    """
    Parse a structured JSON response from the Cortex LLM.

    Claude-class models frequently wrap their JSON output in markdown fences
    (```json ... ```) even when the system prompt instructs plain JSON.
    Strip fences before parsing.

    Args:
        raw_response: Raw text response from the Cortex model.

    Returns:
        Parsed dict.

    Raises:
        LLMServiceError: If the response is not valid JSON after fence stripping.
    """
    import json

    text = raw_response.strip()
    if text.startswith("```"):
        text = text.split("\n", 1)[-1]   # drop opening fence line
        text = text.rsplit("```", 1)[0]  # drop closing fence
        text = text.strip()

    try:
        return json.loads(text)
    except json.JSONDecodeError as error:
        raise LLMServiceError(
            f"Cortex response is not valid JSON: {str(error)}"
        ) from error
```

> **When to use `_parse_json_response`:** Any feature that instructs the LLM to respond with
> a JSON schema (e.g., regulation summaries, structured extractions) **must** call this helper
> instead of `json.loads()` directly. Always include the fence-stripping step — Claude-class
> models consistently wrap JSON in fences despite system prompt instructions to the contrary.

## Authentication Reference

### Azure AD (FastAPI / Interactive)

The first call to `LIGHTClient()` (Azure AD mode) triggers a **device code flow**:

1. A URL and one-time code are printed to the terminal.
2. The user visits the URL, enters the code, and authenticates with their corporate credentials.
3. The token is cached on disk and refreshed automatically.

**No environment variables needed** for the device code flow itself — the OAuth config (tenant ID, client IDs per env) is embedded in `light_client/client_config.ini`.

### AWS IAM (Lambda)

When `auth_method=AUTH_METHOD_AWS`, `LIGHTClient` generates SigV4 headers using the Lambda execution role credentials from the environment (automatically injected by the Lambda runtime). No explicit AWS credentials configuration is needed in code.

**IAM permissions required on the Lambda execution role:**

  "Action": ["sts:GetCallerIdentity"],
  "Resource": "*"
}
```

Plus any additional permissions required to access the Cortex API's VPC endpoint or resource policy.

### Step R3 — Update `src/integrations/cortex_client.py`

Add four RAGAS evaluation functions to the existing `cortex_client.py`. These go after the existing `call_model()` function.

The Cortex RAGAS bulk workflow is **fully asynchronous**:
1. `evaluate_with_ragas_bulk()` — submits the job; returns `{job_id, filepath}` immediately
2. `get_ragas_job_status()` — polls the job until `COMPLETED`
3. `fetch_ragas_evaluation()` — retrieves the final scores by filename

```python
def evaluate_with_ragas(
    question: str,
    ground_truth: str,
    model_name: Optional[str] = None,
    metrics: Optional[List[str]] = None,
) -> Dict[str, Any]:
    """
    Evaluate a single question/answer pair using Cortex RAGAS metrics.

    Calls GET /model/evaluate-rag/{model} with the provided question and
    ground truth to return per-metric scores.

    Args:
        question: The input query to evaluate.
        ground_truth: The reference answer for comparison.
        model_name: Cortex model name. Defaults to CORTEX_PRIMARY_MODEL.
        metrics: RAGAS metrics to compute. Defaults to RAGAS_DEFAULT_METRICS.

    Returns:
        Dict with keys:
            - status (str): "success" or "error"
            - ragas_scores (List[Dict]): Per-metric scores (on success)
            - error_message (str): Error description (on failure)
            - error_code (int): HTTP status code (on failure)
    """
    target_model = model_name or CORTEX_PRIMARY_MODEL
    target_metrics = metrics or RAGAS_DEFAULT_METRICS

    for attempt in range(CORTEX_MAX_RETRIES):
        try:
            client = get_authenticated_client(force_refresh=(attempt > 0))
            params = {
                "q": question,
                "ground_truth": ground_truth,
                "metrics": target_metrics,
            }
            result = client.get(
                f"{CORTEX_BASE}/model/evaluate-rag/{target_model}",
                params=params,
            )

            if result.status_code == 200:
                return {"status": "success", "ragas_scores": result.json()}

            # Cortex RAGAS may return HTTP 500 with "invalid token" body when
            # the token is stale — treat it the same as 403 for retry purposes.
            is_auth_error = result.status_code == 403 or (
                result.status_code == 500 and "invalid token" in result.text.lower()
            )
            if is_auth_error and attempt < CORTEX_MAX_RETRIES - 1:
                logger.warning(
                    "Cortex RAGAS auth error, retrying with fresh token: status=%s",
                    result.status_code,
                )
                time.sleep(2)
                continue

            return {
                "status": "error",
                "error_code": result.status_code,
                "error_message": result.text,
            }

        except Exception as exc:
            if attempt < CORTEX_MAX_RETRIES - 1:
                logger.warning(
                    "Cortex RAGAS call error, retrying",
                    extra={"attempt": attempt + 1, "error": str(exc)},
                )
                time.sleep(2)
                continue
            logger.error(
                "Cortex RAGAS evaluation failed after all retries",
                extra={"max_retries": CORTEX_MAX_RETRIES, "error": str(exc)},
            )
            return {"status": "error", "error_message": str(exc)}

    return {"status": "error", "error_message": f"Failed after {CORTEX_MAX_RETRIES} attempts"}


def evaluate_with_ragas_bulk(
    evaluation_pairs: List[Dict[str, str]],
    model_name: Optional[str] = None,
    metrics: Optional[List[str]] = None,
    batch_size: Optional[int] = None,
    workflow_timeout: Optional[int] = None,
) -> Dict[str, Any]:
    """
    Submit a batch of question/ground-truth pairs to the Cortex RAGAS bulk endpoint.

    Calls POST /model/evaluate-rag/{model}/bulk. Returns immediately with a
    job_id and filepath — the job runs asynchronously. Use get_ragas_job_status()
    to poll for completion and fetch_ragas_evaluation() to retrieve results.

    Args:
        evaluation_pairs: List of dicts with "question" and "ground_truth" keys.
        model_name: Cortex model name. Defaults to CORTEX_PRIMARY_MODEL.
        metrics: RAGAS metrics to compute. Defaults to RAGAS_DEFAULT_METRICS.
        batch_size: Items per batch (1–50). Defaults to RAGAS_BATCH_SIZE.
        workflow_timeout: Max seconds to wait. Defaults to RAGAS_WORKFLOW_TIMEOUT.

    Returns:
        Dict with keys:
            - status (str): "success" or "error"
            - job_id (str): Async job ID (on success)
            - filepath (str): Filename for fetch_ragas_evaluation (on success)
            - error_message (str): Error description (on failure)
            - error_code (int): HTTP status code (on failure)
    """
    target_model = model_name or CORTEX_PRIMARY_MODEL
    target_metrics = metrics or RAGAS_DEFAULT_METRICS
    target_batch_size = batch_size or RAGAS_BATCH_SIZE
    target_timeout = workflow_timeout or RAGAS_WORKFLOW_TIMEOUT

    for attempt in range(CORTEX_MAX_RETRIES):
        try:
            client = get_authenticated_client(force_refresh=(attempt > 0))
            params = {
                "metrics": target_metrics,
                "batch_size": target_batch_size,
                "workflow_timeout": target_timeout,
            }
            result = client.post(
                f"{CORTEX_BASE}/model/evaluate-rag/{target_model}/bulk",
                params=params,
                json=evaluation_pairs,
            )

            if result.status_code == 200:
                data = result.json()
                return {
                    "status": "success",
                    "job_id": data.get("job_id"),
                    "filepath": data.get("filepath"),
                }

            if result.status_code == 403 and attempt < CORTEX_MAX_RETRIES - 1:
                logger.warning(
                    "Cortex RAGAS bulk auth error, retrying",
                    extra={"attempt": attempt + 1, "max_retries": CORTEX_MAX_RETRIES},
                )
                time.sleep(2)
                continue

            return {
                "status": "error",
                "error_code": result.status_code,
                "error_message": result.text,
            }

        except Exception as exc:
            if attempt < CORTEX_MAX_RETRIES - 1:
                logger.warning(
                    "Cortex RAGAS bulk call error, retrying",
                    extra={"attempt": attempt + 1, "error": str(exc)},
                )
                time.sleep(2)
                continue
            logger.error(
                "Cortex RAGAS bulk evaluation failed after all retries",
                extra={"max_retries": CORTEX_MAX_RETRIES, "error": str(exc)},
            )
            return {"status": "error", "error_message": str(exc)}

    return {"status": "error", "error_message": f"Failed after {CORTEX_MAX_RETRIES} attempts"}


def get_ragas_job_status(job_id: str) -> Dict[str, Any]:
    """
    Poll the status of an async RAGAS bulk evaluation job.

    Calls GET /model/evaluate-rag/job-status/{job_id}.

    Args:
        job_id: The job ID returned by evaluate_with_ragas_bulk.

    Returns:
        Dict with keys:
            - status (str): "success" or "error"
            - job_status (str): "QUEUED", "PROCESSING", or "COMPLETED"
            - data (Dict): Full Cortex job status response (on success)
            - error_message (str): Error description (on failure)
            - error_code (int): HTTP status code (on failure)
    """
    try:
        client = get_authenticated_client()
        result = client.get(f"{CORTEX_BASE}/model/evaluate-rag/job-status/{job_id}")

        if result.status_code == 200:
            data = result.json()
            return {
                "status": "success",
                "job_status": data.get("status"),
                "data": data,
            }

        return {
            "status": "error",
            "error_code": result.status_code,
            "error_message": result.text,
        }

    except Exception as exc:
        logger.error(
            "Cortex RAGAS job status check failed",
            extra={"job_id": job_id, "error": str(exc)},
        )
        return {"status": "error", "error_message": str(exc)}


def fetch_ragas_evaluation(model_name: str, file_name: str) -> Dict[str, Any]:
    """
    Fetch completed RAGAS evaluation results by filename.

    Calls GET /model/evaluate-rag/{model}/fetch_evaluation/{file_name}.

    Cortex returns {"status": "success", "result": [...]} on completion, or
    {"message": "..."} when the job is still processing.

    Args:
        model_name: Cortex model name.
        file_name: The filepath returned by evaluate_with_ragas_bulk.

    Returns:
        Dict with keys:
            - status (str): "success", "not_found", or "error"
            - result (List[Dict]): Per-item evaluation scores (on success)
            - message (str): Not-found message when job still processing
            - error_message (str): Error description (on failure)
            - error_code (int): HTTP status code (on failure)
    """
    try:
        client = get_authenticated_client()
        result = client.get(
            f"{CORTEX_BASE}/model/evaluate-rag/{model_name}/fetch_evaluation/{file_name}"
        )

        if result.status_code == 200:
            data = result.json()
            if isinstance(data, dict) and "message" in data:
                return {"status": "not_found", "message": data["message"]}
            # Cortex returns {"status": "success", "result": [...]} — unwrap the list
            result_data = data.get("result", data) if isinstance(data, dict) else data
            return {"status": "success", "result": result_data}

        return {
            "status": "error",
            "error_code": result.status_code,
            "error_message": result.text,
        }

    except Exception as exc:
        logger.error(
            "Cortex RAGAS fetch evaluation failed",
            extra={"model_name": model_name, "file_name": file_name, "error": str(exc)},
        )
        return {"status": "error", "error_message": str(exc)}
```

### Step R4 — Create `src/services/ragas_evaluation_service.py`

This framework-agnostic service wraps the `cortex_client` RAGAS functions and applies project-level validation logic. It is callable from both FastAPI routes and Lambda handlers.

The service exposes four functions matching the four async workflow stages:

```python
"""
RAGAS evaluation service.

Provides framework-agnostic single-shot and async bulk AI output evaluation
using the Cortex RAGAS API.
"""

import logging
from typing import Any, Dict, List, Optional

from src.core.config import CORTEX_PRIMARY_MODEL, RAGAS_DEFAULT_METRICS
from src.core.exceptions import RAGASEvaluationError
from src.integrations.cortex_client import (
    evaluate_with_ragas,
    evaluate_with_ragas_bulk,
    fetch_ragas_evaluation,
    get_ragas_job_status,
)

logger = logging.getLogger(__name__)

VALID_METRICS = {
    "answer_correctness",
    "answer_relevancy",
    "semantic_similarity",
    "context_entity_recall",
    "context_precision",
    "context_recall",
    "context_utilization",
    "faithfulness",
}


def validate_metrics(metrics: List[str]) -> None:
    """
    Validate that all requested RAGAS metrics are supported.

    Raises:
        ValueError: If any metric name is not in the supported set.
    """
    invalid = set(metrics) - VALID_METRICS
    if invalid:
        raise ValueError(
            f"Unsupported RAGAS metrics: {invalid}. "
            f"Valid options: {sorted(VALID_METRICS)}"
        )


def evaluate_single(
    question: str,
    ground_truth: str,
    model_name: Optional[str] = None,
    metrics: Optional[List[str]] = None,
) -> Dict[str, Any]:
    """
    Evaluate a single question/answer pair with RAGAS.

    Returns:
        Dict of per-metric float scores keyed by metric name.

    Raises:
        ValueError: If any metric name is invalid.
        RAGASEvaluationError: If the Cortex RAGAS call fails.
    """
    effective_metrics = metrics or RAGAS_DEFAULT_METRICS
    validate_metrics(effective_metrics)

    logger.info("Running single RAGAS evaluation", extra={"metrics": effective_metrics})

    result = evaluate_with_ragas(
        question=question,
        ground_truth=ground_truth,
        model_name=model_name,
        metrics=effective_metrics,
    )

    if result["status"] != "success":
        raise RAGASEvaluationError(
            f"RAGAS evaluation failed: {result.get('error_message', 'unknown error')}"
        )

    ragas_scores = result["ragas_scores"]
    # Cortex RAGAS single endpoint returns a list — unwrap to a single item dict
    if isinstance(ragas_scores, list):
        ragas_scores = ragas_scores[0] if ragas_scores else {}

    return ragas_scores


def evaluate_bulk(
    evaluation_pairs: List[Dict[str, str]],
    model_name: Optional[str] = None,
    metrics: Optional[List[str]] = None,
    batch_size: Optional[int] = None,
    workflow_timeout: Optional[int] = None,
) -> Dict[str, Any]:
    """
    Submit a batch of question/answer pairs for async RAGAS bulk evaluation.

    Returns immediately with job_id and filepath. Use get_job_status() to
    poll for completion and fetch_evaluation() to retrieve scores.

    Returns:
        {"job_id": "...", "filepath": "..."}

    Raises:
        ValueError: If evaluation_pairs is empty or any metric is invalid.
        RAGASEvaluationError: If the Cortex RAGAS bulk call fails.
    """
    if not evaluation_pairs:
        raise ValueError("evaluation_pairs must not be empty.")

    effective_metrics = metrics or RAGAS_DEFAULT_METRICS
    validate_metrics(effective_metrics)

    logger.info(
        "Submitting bulk RAGAS evaluation",
        extra={"pair_count": len(evaluation_pairs), "metrics": effective_metrics},
    )

    result = evaluate_with_ragas_bulk(
        evaluation_pairs=evaluation_pairs,
        model_name=model_name,
        metrics=effective_metrics,
        batch_size=batch_size,
        workflow_timeout=workflow_timeout,
    )

    if result["status"] != "success":
        raise RAGASEvaluationError(
            f"RAGAS bulk evaluation failed: {result.get('error_message', 'unknown error')}"
        )

    return {"job_id": result["job_id"], "filepath": result["filepath"]}


def get_job_status(job_id: str) -> Dict[str, Any]:
    """
    Get the status of an async RAGAS bulk evaluation job.

    Returns:
        Full Cortex job status response data dict.

    Raises:
        RAGASEvaluationError: If the Cortex status call fails.
    """
    result = get_ragas_job_status(job_id=job_id)

    if result["status"] != "success":
        raise RAGASEvaluationError(
            f"Failed to get job status: {result.get('error_message', 'unknown error')}"
        )

    return result["data"]


def fetch_evaluation(model_name: Optional[str], file_name: str) -> Dict[str, Any]:
    """
    Fetch completed RAGAS evaluation results by filename.

    Returns:
        {"status": "success", "result": [...]} on completion, or
        {"status": "not_found", "message": "..."} when still processing.

    Raises:
        RAGASEvaluationError: If the Cortex fetch call fails.
    """
    target_model = model_name or CORTEX_PRIMARY_MODEL
    result = fetch_ragas_evaluation(model_name=target_model, file_name=file_name)

    if result["status"] == "error":
        raise RAGASEvaluationError(
            f"Failed to fetch evaluation: {result.get('error_message', 'unknown error')}"
        )

    return result
```

"""RAGAS evaluation API routes."""

import logging
from typing import Optional

from fastapi import APIRouter, HTTPException, status

from src.core.exceptions import RAGASEvaluationError
from src.models.requests import BulkEvaluationRequest
from src.models.responses import (
    BulkEvaluationResponse,
    FetchEvaluationResponse,
    JobStatusResponse,
    SingleEvaluationResponse,
)
from src.services import ragas_evaluation_service

logger = logging.getLogger(__name__)

router = APIRouter(prefix="/api/v1/evaluation", tags=["evaluation"])


@router.get("/ragas", response_model=SingleEvaluationResponse, status_code=status.HTTP_200_OK)
def evaluate_single_endpoint(
    question: str,
    ground_truth: str,
    metrics: Optional[str] = None,
    model_name: Optional[str] = None,
) -> SingleEvaluationResponse:
    """Evaluate a single question/answer pair using RAGAS metrics."""
    metric_list = (
        [m.strip() for m in metrics.split(",") if m.strip()] if metrics else None
    )
    try:
        scores = ragas_evaluation_service.evaluate_single(
            question=question,
            ground_truth=ground_truth,
            model_name=model_name,
            metrics=metric_list,
        )
    except ValueError as error:
        raise HTTPException(status_code=status.HTTP_400_BAD_REQUEST, detail=str(error)) from error
    except RAGASEvaluationError as error:
        raise HTTPException(status_code=status.HTTP_502_BAD_GATEWAY, detail=str(error)) from error
    except Exception as error:
        logger.error("Unexpected error in single RAGAS evaluation", extra={"error": str(error)}, exc_info=True)
        raise HTTPException(status_code=status.HTTP_500_INTERNAL_SERVER_ERROR, detail="An unexpected error occurred.") from error

    return SingleEvaluationResponse(scores=scores)


@router.post("/ragas/bulk", response_model=BulkEvaluationResponse, status_code=status.HTTP_200_OK)
def evaluate_bulk_endpoint(payload: BulkEvaluationRequest) -> BulkEvaluationResponse:
    """Submit a batch of question/answer pairs for async RAGAS evaluation.

    Returns immediately with job_id and filepath. Poll with
    GET /ragas/job-status/{job_id} and fetch results with
    GET /ragas/fetch/{model_name}/{file_name} once COMPLETED.
    """
    pairs_as_dicts = [pair.model_dump() for pair in payload.evaluation_pairs]
    try:
        result = ragas_evaluation_service.evaluate_bulk(
            evaluation_pairs=pairs_as_dicts,
            model_name=payload.model_name,
            metrics=payload.metrics,
            batch_size=payload.batch_size,
            workflow_timeout=payload.workflow_timeout,
        )
    except ValueError as error:
        raise HTTPException(status_code=status.HTTP_400_BAD_REQUEST, detail=str(error)) from error
    except RAGASEvaluationError as error:
        raise HTTPException(status_code=status.HTTP_502_BAD_GATEWAY, detail=str(error)) from error
    except Exception as error:
        logger.error("Unexpected error in bulk RAGAS evaluation", extra={"error": str(error)}, exc_info=True)
        raise HTTPException(status_code=status.HTTP_500_INTERNAL_SERVER_ERROR, detail="An unexpected error occurred.") from error

    return BulkEvaluationResponse(job_id=result["job_id"], filepath=result["filepath"])


@router.get("/ragas/job-status/{job_id}", response_model=JobStatusResponse, status_code=status.HTTP_200_OK)
def get_job_status_endpoint(job_id: str) -> JobStatusResponse:
    """Poll the status of an async RAGAS bulk evaluation job.

    Status progresses: QUEUED → PROCESSING → COMPLETED.
    """
    try:
        data = ragas_evaluation_service.get_job_status(job_id=job_id)
    except RAGASEvaluationError as error:
        raise HTTPException(status_code=status.HTTP_502_BAD_GATEWAY, detail=str(error)) from error
    except Exception as error:
        logger.error("Unexpected error fetching RAGAS job status", extra={"job_id": job_id, "error": str(error)}, exc_info=True)
        raise HTTPException(status_code=status.HTTP_500_INTERNAL_SERVER_ERROR, detail="An unexpected error occurred.") from error

    return JobStatusResponse(
        status=data.get("status"),
        job_id=data.get("job_id"),
        type=data.get("type"),
        domain=data.get("domain"),
        input=data.get("input"),
        result=data.get("result"),
    )


@router.get("/ragas/fetch/{model_name}/{file_name}", response_model=FetchEvaluationResponse, status_code=status.HTTP_200_OK)
def fetch_evaluation_endpoint(model_name: str, file_name: str) -> FetchEvaluationResponse:
    """Fetch completed RAGAS evaluation results by model name and filename.

    Returns status='not_found' if the job is still processing, or
    status='success' with per-item scores once the job completes.
    """
    try:
        result = ragas_evaluation_service.fetch_evaluation(
            model_name=model_name,
            file_name=file_name,
        )
    except RAGASEvaluationError as error:
        raise HTTPException(status_code=status.HTTP_502_BAD_GATEWAY, detail=str(error)) from error
    except Exception as error:
        logger.error(
            "Unexpected error fetching RAGAS evaluation",
            extra={"model_name": model_name, "file_name": file_name, "error": str(error)},
            exc_info=True,
        )
        raise HTTPException(status_code=status.HTTP_500_INTERNAL_SERVER_ERROR, detail="An unexpected error occurred.") from error

    if result["status"] == "not_found":
        return FetchEvaluationResponse(status="not_found", message=result["message"])

    return FetchEvaluationResponse(status="success", result=result["result"])
```

```python
"""RAGAS evaluation Lambda handler."""

import json
import logging
from typing import Any, Dict

from src.core.exceptions import RAGASEvaluationError
from src.services.ragas_evaluation_service import (
    evaluate_single,
    evaluate_bulk,
    get_job_status,
    fetch_evaluation,
)
from src.utils.lambda_response import build_response

logger = logging.getLogger(__name__)
logger.setLevel(logging.INFO)


def lambda_handler(event: Dict[str, Any], context: Any) -> Dict[str, Any]:
    """
    AWS Lambda handler for RAGAS evaluation.

    Routes:
        GET  /evaluation/ragas                             → single-shot evaluation
        POST /evaluation/ragas/bulk                        → submit async bulk job
        GET  /evaluation/ragas/job-status/{job_id}         → poll job status
        GET  /evaluation/ragas/fetch/{model}/{file_name}   → fetch completed results
    """
    http_method = event.get("httpMethod", "")
    path = event.get("path", "")
    path_params = event.get("pathParameters") or {}

    try:
        if http_method == "GET" and path.endswith("/ragas"):
            params = event.get("queryStringParameters") or {}
            question = params.get("question", "").strip()
            ground_truth = params.get("ground_truth", "").strip()
            metrics_raw = params.get("metrics", "")
            model_name = params.get("model_name") or None
            metric_list = [m.strip() for m in metrics_raw.split(",") if m.strip()] if metrics_raw else None

            if not question or not ground_truth:
                return build_response(400, {"error": "question and ground_truth are required"})

            scores = evaluate_single(
                question=question,
                ground_truth=ground_truth,
                model_name=model_name,
                metrics=metric_list,
            )
            return build_response(200, {"scores": scores})

        if http_method == "POST" and path.endswith("/bulk"):
            body = json.loads(event.get("body") or "{}")
            evaluation_pairs = body.get("evaluation_pairs", [])
            model_name = body.get("model_name") or None
            metrics = body.get("metrics") or None
            batch_size = body.get("batch_size") or None
            workflow_timeout = body.get("workflow_timeout") or None

            if not evaluation_pairs:
                return build_response(400, {"error": "evaluation_pairs is required"})

            result = evaluate_bulk(
                evaluation_pairs=evaluation_pairs,
                model_name=model_name,
                metrics=metrics,
                batch_size=batch_size,
                workflow_timeout=workflow_timeout,
            )
            return build_response(200, result)

        if http_method == "GET" and "/job-status/" in path:
            job_id = path_params.get("job_id") or path.rsplit("/", 1)[-1]
            data = get_job_status(job_id=job_id)
            return build_response(200, data)

        if http_method == "GET" and "/fetch/" in path:
            model_name = path_params.get("model_name")
            file_name = path_params.get("file_name")
            result = fetch_evaluation(model_name=model_name, file_name=file_name)
            return build_response(200, result)

        return build_response(404, {"error": "Route not found"})

    except ValueError as exc:
        logger.warning("RAGAS validation error: %s", str(exc))
        return build_response(400, {"error": str(exc)})
    except RAGASEvaluationError as exc:
        logger.error("RAGAS evaluation error: %s", str(exc))
        return build_response(502, {"error": str(exc)})
    except Exception as exc:
        logger.error("Unexpected evaluation error: %s", str(exc), exc_info=True)
        return build_response(500, {"error": "Internal server error"})
```

from typing import Any, Dict, List, Optional
from pydantic import BaseModel, Field


class SingleEvaluationResponse(BaseModel):
    """Response for GET /api/v1/evaluation/ragas (single-shot evaluation)."""

    scores: Dict[str, Any] = Field(
        default_factory=dict,

    """

        ...,
        description="Async job ID — use with GET /api/v1/evaluation/ragas/job-status/{job_id}.",

        ...,
        description="Result filename — use with GET /api/v1/evaluation/ragas/fetch/{model}/{file_name}.",

    ground_truth: str

    answer_relevancy: Optional[float] = None
    answer_similarity: Optional[float] = None
    faithfulness: Optional[float] = None

    context_recall: Optional[float] = None

    semantic_similarity: Optional[float] = None


class FetchEvaluationResponse(BaseModel):

> ```python
> result_data = data.get("result", data) if isinstance(data, dict) else data
> return {"status": "success", "result": result_data}
> ```

| `deployment_name` | Azure deployment name (for OpenAI-backed models) |
| `model_type` | Type category (e.g., `"chat"`, `"embedding"`) |
| `token_limit` | Maximum context tokens |
| `is_deprecated` | Whether the model is deprecated |

## Checklist

Use this checklist after implementing Cortex integration:

- [ ] `light_client/` folder is present at project root and unmodified
- [ ] `scripts/create_cortex_model.py` generated (if `Cortex Model Name` = NEW); developer has run it and recorded the returned name in `PROJECT_OVERVIEW.md`
- [ ] `CORTEX_BASE`, `CORTEX_PRIMARY_MODEL`, `CORTEX_AUTH_ENV`, `CORTEX_REQUEST_TIMEOUT` are set in `.env.example` (no hardcoded values)
- [ ] `src/integrations/cortex_client.py` created from template
- [ ] `import requests as _requests` added at top of `cortex_client.py`; `call_model()` catches both `TimeoutError` and `_requests.exceptions.Timeout`
- [ ] `call_model()` accepts `timeout` parameter; sets `timed_out: True` in result dict on timeout
- [ ] `_AUTH_METHOD` in `cortex_client.py` matches deployment target (Azure AD for FastAPI; AWS for Lambda)
- [ ] `LLMServiceError` and `LLMTimeoutError` added to `src/core/exceptions.py`
- [ ] `src/core/config.py` updated with Cortex env vars including `CORTEX_REQUEST_TIMEOUT`
- [ ] Service layer calls `cortex_client.call_model()` — no direct `LIGHTClient` usage in services
- [ ] FastAPI route OR Lambda handler updated to call service layer (not `cortex_client` directly)
- [ ] `requirements.txt` updated: `requests` for both; `boto3`/`botocore` only for Lambda
- [ ] No Cortex model names hardcoded in source files (all from env / config)
- [ ] No secrets or tokens logged
- [ ] **FastMCP (if target includes FastMCP):** `src/mcp_server/server.py` generated with FastMCP version matching `PROJECT_OVERVIEW.md`; transport read from `MCP_TRANSPORT` env (no hardcoding); MCP server name read from `MCP_SERVER_NAME` env
- [ ] **FastMCP (if target includes FastMCP):** MCP tools live under `src/mcp_server/tools/` and call `src/services/` — never `cortex_client` or `LIGHTClient` directly
- [ ] **FastMCP (if target includes FastMCP):** `requirements.txt` pins `fastmcp>=2.0` (the default), or `mcp>=1.0` only when the project explicitly requires FastMCP 1.x — never both
- [ ] **FastMCP (if target includes FastMCP):** `.env.example` includes `MCP_SERVER_NAME`, `MCP_TRANSPORT`, `MCP_HOST`, `MCP_PORT`
- [ ] **RAGAS (if applicable):** See RAGAS Checklist in the RAGAS Evaluation Integration section above

## Common Errors and Resolutions

| Error | Likely Cause | Resolution |
|-------|-------------|------------|
| HTTP 403 on first call | Token not yet obtained or expired | For Azure AD: complete device code flow in terminal. For AWS: verify Lambda execution role has `sts:GetCallerIdentity` permission. |
| `ModuleNotFoundError: light_client` | `light_client/` not on Python path | Ensure `light_client/` is at the project root, not inside `src/`. Import works when running from project root. |
| `json.JSONDecodeError` on LLM response | Claude-class models wrap JSON in markdown fences (` ```json ... ``` `) despite being told not to | Strip fences before `json.loads()`: `if text.startswith("```"): text = text.split("\n",1)[-1].rsplit("```",1)[0].strip()` |
| `ValidationError: result — Input should be a valid list, input_type=dict` | `fetch_ragas_evaluation()` passed the full Cortex envelope `{"status": "success", "result": [...]}` to `FetchEvaluationResponse` instead of the inner list | Unwrap the `result` key: `result_data = data.get("result", data) if isinstance(data, dict) else data` before returning from `fetch_ragas_evaluation()`. `FetchEvaluationResponse.result` expects `List[FetchEvaluationItem]`, not a dict. |
| RAGAS single endpoint returns HTTP 500 `"invalid token"` | Cortex RAGAS endpoint returns `500` (not `403`) when the token is stale | Retry logic in `evaluate_with_ragas()` must check both: `result.status_code == 403 or (result.status_code == 500 and "invalid token" in result.text.lower())` |
| Bulk submit returns `{job_id, filepath}` but service/route expects `{ragas_scores}` | Old synchronous bulk pattern used — `evaluate_with_ragas_bulk()` returns job reference, not scores | Cortex bulk is **fully async**. The bulk endpoint returns `{job_id, filepath}` immediately. Implement the three-step workflow: submit → poll job-status → fetch results. |
| HTTP 404 on model call | Model name is wrong or model is deprecated | Call `list_available_models()` to get current names; check `is_deprecated` field. |
| HTTP 429 / rate limit | Too many concurrent requests | Add exponential backoff; `CORTEX_MAX_RETRIES` already handles transient failures. |
| Token cache file permission error | `light_client` tries to write cached token to disk | Ensure write permissions on the user home directory; relevant for containerized deployments. |
| `LLMTimeoutError` on regulation summary | Model call exceeds `CORTEX_REQUEST_TIMEOUT` | `call_model()` catches both `TimeoutError` and `requests.exceptions.Timeout`. Set `CORTEX_REQUEST_TIMEOUT` env var to increase timeout. `timed_out: True` is set in the result dict. |
| `ImportError: cannot import name 'FastMCP' from 'fastmcp'` | `fastmcp` package not installed, or the project is pinned to FastMCP 1.x but the code imports from `fastmcp` | Default is FastMCP 2.x — install `fastmcp>=2.0` and use `from fastmcp import FastMCP`. If pinned to 1.x, install `mcp>=1.0` and import from `mcp.server.fastmcp` instead. Never install both packages in the same project. |
| MCP tool returns nothing or hangs the AI client | Tool raised an exception that wasn't converted to `ToolError`; client sees an opaque protocol-level error | Wrap service-layer exceptions and raise `fastmcp.exceptions.ToolError(...)` from them. Always log the original exception to the standard logger before raising `ToolError` so the cause is visible server-side. |
| `MCP_TRANSPORT` env unset / `ValueError: Unsupported MCP_TRANSPORT` at startup | Transport not configured or set to a value not in `{stdio, streamable-http, sse}` | Set `MCP_TRANSPORT` to match the value in `PROJECT_OVERVIEW.md`. The server defaults to `stdio` when unset; the `ValueError` is raised by `src/mcp_server/server.py:main()` for any other value. |

## Notes for Copilot

1. **This file is only consulted when `LLM Provider: Cortex` is set in `PROJECT_OVERVIEW.md`.** If that field is absent or set to another provider, ignore this file entirely.
2. **Never modify `light_client/`** — treat it as a vendored library.
3. **Model names come from `PROJECT_OVERVIEW.md`** — never invent them.
4. **Auth method is inferred from deployment target** — Azure AD for FastAPI, AWS for Lambda. Ask the user only if deployment target is ambiguous.
5. **`cortex_client.py` is the only file that imports from `light_client`** — all other modules use it through `src/integrations/cortex_client`.
6. **The `call_model()` function is the primary integration point** — for advanced use cases (RAG evaluation, model listing), expose additional functions from `cortex_client.py` only when the feature specification requires them.
7. **RAGAS integration is conditional** — only generate RAGAS files when the project's BRD, User Stories, or `PROJECT_OVERVIEW.md` explicitly require AI output evaluation (e.g., answer correctness benchmarking, model comparison, RAG quality assessment). If evaluation intent is ambiguous, ask the user before generating. Never generate RAGAS files speculatively.
8. **RAGAS metric names must not be hardcoded** — always read from `RAGAS_DEFAULT_METRICS` env var / config. Never invent metric names outside the documented valid set.
9. **FastMCP tools must wrap services, not the Cortex client** — when `Deployment Target` includes FastMCP, MCP tools (`src/mcp_server/tools/`) call `src/services/<feature>_service.py` functions exactly like FastAPI routes do. Never import `LIGHTClient` or call `cortex_client` from MCP modules. This keeps REST and MCP behavior identical and is enforced by the framework's "MCP service-layer bypass" guardrail.
10. **FastMCP defaults to 2.x** — `from fastmcp import FastMCP`. Use FastMCP 1.x imports (`from mcp.server.fastmcp import FastMCP`) only when the project explicitly pins 1.x. Never mix the two in one project.
