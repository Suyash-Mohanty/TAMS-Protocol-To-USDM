# Evaluation Metrics — AI-First Backend Workflow

## Purpose

This document defines **evaluation criteria, scoring rubrics, and verification procedures** for assessing the quality of code generated by GitHub Copilot (Agent Mode) using the AI-First Backend Workflow framework. Use this after each Level 1 (Foundation) or Level 2 (Feature Implementation) execution to measure output quality and identify improvement areas.

---

## 1. Evaluation Overview

### Evaluation Dimensions

| Dimension | Description | Applies To |
|-----------|-------------|------------|
| **Structural Completeness** | All required files, folders, and boilerplate are generated | Level 1, Level 2 |
| **API Contract Fidelity** | Endpoints, request/response schemas match `FEATURE_IMPLEMENTATION.md` | Level 2 |
| **Coding Standards Compliance** | Adherence to `PYTHON_CODING_STANDARDS.md` | Level 1, Level 2 |
| **Security Posture** | No hardcoded secrets, proper input validation, auth enforcement | Level 1, Level 2 |
| **Functional Correctness** | Business logic matches acceptance criteria; tests pass | Level 2 |
| **Error Handling** | Specific exceptions, proper logging, graceful degradation | Level 2 |

### Scoring Scale

| Score | Label | Description |
|-------|-------|-------------|
| 5 | **Excellent** | Fully meets criteria with no issues; production-ready |
| 4 | **Good** | Meets criteria with minor issues that do not affect functionality |
| 3 | **Acceptable** | Meets most criteria but has notable gaps requiring fixes |
| 2 | **Below Expectations** | Significant gaps; requires substantial rework |
| 1 | **Poor** | Major gaps; requires significant rework or regeneration |
| 0 | **Unacceptable** | Fails to meet criteria; must be regenerated or rewritten |

### Pass/Fail Thresholds

| Level | Minimum Average Score | Hard Fail Conditions |
|-------|-----------------------|----------------------|
| Level 1 (FastAPI) | 3.5 / 5.0 | Any dimension scored 0; missing `main.py` or `config.py` |
| Level 1 (AWS Lambda) | 3.5 / 5.0 | Any dimension scored 0; missing `health_handler.py` or `config.py`; FastAPI/Mangum imports in handlers |
| Level 1 (Cortex) | 3.5 / 5.0 | `LLM Provider: Cortex` set but `light_client/` absent; `cortex_client.py` missing; Cortex model name hardcoded |
| Level 1 (Cortex + RAGAS) | 3.5 / 5.0 | RAGAS evaluation required but `ragas_evaluation_service.py` missing; `RAGASEvaluationError` missing; RAGAS metric names hardcoded |
| Level 2 | 3.5 / 5.0 | Any dimension scored 0; API contract mismatch; hardcoded secrets; frontend code generated; wrong deployment target artifacts generated; Cortex model name hardcoded when `LLM Provider: Cortex`; RAGAS files missing when evaluation is required; RAGAS metric names hardcoded |

## 3. Level 2: Feature Implementation Evaluation

### 3.1 API Contract Fidelity

For each endpoint defined in `FEATURE_IMPLEMENTATION.md`, verify:

| # | Endpoint | Method Match | Path Match | Request Schema Match | Response Schema Match | Status Codes Match | Auth Required Match | Score (1-5) |
|---|----------|-------------|------------|---------------------|-----------------------|-------------------|---------------------|-------------|
| 1 | POST /api/dashboard | | | | | | | |
| 2 | PATCH /api/assessments/{assessment_id} | | | | | | | |

**Contract Fidelity Details:**

For each endpoint, evaluate:

| Check | Description | Scoring Guidance |
|-------|-------------|------------------|
| Method Match | HTTP method matches spec | 5=exact, 1=wrong method |
| Path Match | Route path matches spec exactly | 5=exact, 3=minor deviation, 1=wrong path |
| Request Schema Match | All fields, types, validations present | 5=all fields correct, 3=missing optional fields, 1=missing required fields |
| Response Schema Match | Response envelope, data fields, types match | 5=exact match, 3=minor deviations, 1=missing key fields |
| Status Codes Match | All expected status codes handled | 5=all codes, 3=missing edge cases, 1=only happy path |

### 3.2 Business Logic Correctness

Verify each business rule from `FEATURE_IMPLEMENTATION.md` and score from 0-100%.
